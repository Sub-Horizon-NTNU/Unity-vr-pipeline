# Tredjepartsprogramvare

- **GstUnityPlugin**, William Reed Seal-Foss: [upstream](https://github.com/sealfoss/GstUnityPlugin), CC BY-NC-SA 4.0. Original `LICENSE.md` og README beholdes. Videreføringen legger til ROV/Quest-tilt, bildekalibrering, HUD, konfigurasjon og releaseverktøy.
- **GStreamer 1.28.7 og runtimeavhengigheter**: [prosjekt](https://gstreamer.freedesktop.org/), [kildekode](https://gstreamer.freedesktop.org/src/). Runtime distribueres uendret med egne lisenser under `GStreamer/share/licenses`, inkludert komponentversjoner. Plugins/avhengigheter kan ha ulike lisenser; prosjektets lisens erstatter ikke disse.
- **Unity, Meta XR og øvrige Unity-pakker**: versjoner i `UnityProject/Packages`. Pakker hentes fra registrene og er underlagt leverandørenes vilkår. Pakke-cacher er ikke sjekket inn.
- **Liberation Sans**: SIL Open Font License, se `UnityProject/Assets/ROV/Resources/RovHudFont-LICENSE.txt`. Fonten følger prosjekt og spiller.
- Upstream viser til [Unity NativeRenderingPlugin](https://github.com/Unity-Technologies/NativeRenderingPlugin) og [mrayGStreamerUnity](https://github.com/mrayy/mrayGStreamerUnity). Se den bevarte upstream-README-en for opprinnelse.
